# Trần Phước Thịnh | Portfolio

English personal portfolio featuring equity research, publications, projects and experience.

Website: https://thinhtraniv.github.io/portfolio/

## Local preview

Run `python3 -m http.server 4173` from this directory.

## Deployment

GitHub Pages: deploy from branch `main`, folder `/ (root)`. No build step is required. All local asset URLs are relative and support the `/portfolio/` project path.

Edit `index.html`, `style.css` and `script.js`. Supplied CV and research report are in `assets/`. The candlestick background is decorative; research results are dated team outputs with individual contributions identified separately.
